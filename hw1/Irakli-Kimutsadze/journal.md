## Week 2 . Spec Before Code
Pattern: Spec before code
Where I saw it: In this homework, I passed a short prompt where the function made by AI guessed the input key, which means it never recognized any reach or safe programs, missing the main rule (AC1). By sharing the spec, the mismatch showed up and I was able to get it rewritten.
What I would do differently: I would make a prompt include every detail of the spec next time in order to not miss anything important

## Week 3 . Uncertainty-Aware UX
Pattern: Uncertainty-Aware UX
Where I saw it: When a reach is above a safe, my function warns the user instead of making any adjustments itself. It only returns data, so there are no uncertain changes made. (like reordered, deleted or blocked)
What I would do differently: While I believe it's decent at the moment, I think I could make it convey a clearer warning. The warning says which programs are out of order but not why it's risky, so next time I would add a short reason to the message.
